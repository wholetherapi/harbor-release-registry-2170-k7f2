# Harbor Data Trust - publication registry

Operational records for the current publication cycle.

- `policy/RELEASE_LICENSE_POLICY.md` - release license policy and release-readiness rule.
- `registry/RELEASE_TRACKER.md` - compliance tracker for the cycle.
- `registry/releases/<release_id>/CARD.md` - dataset card for each release.
- `registry/models/<model_id>/CARD.md` - cards for the in-house synthesis models.
- `registry/templates/LICENSE_DECISION_COMMENT.md` - required reply template.
